# Fast Repair — многостраничный сайт автосервиса (HTML/CSS)

> Учебный веб-проект: статический многостраничный сайт автосервиса **Fast Repair**.
> Вёрстка на чистом **HTML + CSS** (без фреймворков). Автор: Бугаев Евгений Валерьевич.

## Страницы
| Файл | Раздел |
|---|---|
| `index.html` | Главная |
| `about.html` | О нас |
| `price.html` | Цены |
| `how_to.html` | Партнёры |
| `contact.html` | Контакты |
| `new/E-BOOKS.html`, `E-JOURNALS.html`, `E-DICTIONARIES.html`, `E-WORKBOOKS.html` | Разделы ресурсов |
| `styles.css` | Общие стили |

## Что демонстрирует
- Многостраничная навигация и единый внешний стиль (`styles.css`).
- Блочная вёрстка, работа с изображениями, партнёрская «бегущая строка», футер с контактами
  и ссылками на соцсети.
- Базовые принципы вёрстки и структурирования проекта.

## Запуск
Открыть `index.html` в браузере (или поднять любой статический сервер).

## Примечание
Использованные логотипы брендов и изображения — учебные материалы и принадлежат их
правообладателям (см. раздел о правах в корневом файле проекта).
